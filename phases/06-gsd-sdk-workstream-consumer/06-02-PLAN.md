    The race test in this plan proves it at the CLI boundary.
  - SC#3 demands a human-runnable demo reproducing the original pain

    pair of pytest test cases — runnable via `bash scripts/test.sh

    values into each child subprocess to avoid Pitfall #4 (same session-id
    triggers Lua refresh, masking race) and Pitfall #5 (uninjected db routes
    children to prod db=0).

    `pytest.skip(..., allow_module_level=True)` if `gsd-sdk` is not on PATH.
    This keeps Phase 6's dependency on a Node binary local to Phase 6 — no
    extension of conftest.py.

<!-- gsd-sdk CLI shape (verified live by 06-RESEARCH.md probes) -->

Invocation:
  gsd-sdk query workstream.set <name> --raw --cwd <project_dir>

Required flags (per workstreams.md slash-command convention):
  --raw          : suppress TTY-pretty output, emit JSON envelope
  --cwd <path>   : tells gsd-sdk which project's .planning/ to operate on

Project layout gsd-sdk requires:
  <cwd>/.planning/workstreams/<name>/STATE.md must exist for existsSync(wsDir)
  check to pass; otherwise gsd-sdk returns {set: false, error: 'not_found'}.

JSON envelope shape after Phase 6 patch (verified against 06-RESEARCH.md
Pattern 1 lines 233-258):
  Winner (status 0):  {"data":{"active":"<name>","set":true,"mirror_synced":<bool>}}
  Loser  (status 3):  {"data":{"active":null,"set":false,"error":"held_by_another",
                              "workstream":"<name>","holder":{...},"message":"..."}}
  Anonymous refused:  {"data":{"active":null,"set":false,"error":"claim_refused",
                              "workstream":"<name>","detail":"..."}}
  ENOENT fallback:    {"data":{"active":"<name>","set":true,"mirror_synced":<bool>}}
                      (legacy success path; stderr contains the warning)
