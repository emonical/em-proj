## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03-01 | Tampering | send --to + --topic mutual exclusion | mitigate | Verb shell checks "if to and topic" BEFORE Redis call; emit_error("validation_error") + exit 1; prevents ambiguous routing |
| T-10-03-02 | Tampering | subscribe topic argument (CLI surface) | mitigate | subscribe_topic (ops layer) calls _validate_topic before SADD; ValidationError propagated to verb shell → emit_error + exit 1; key injection via topic name is blocked |
| T-10-03-03 | Information Disclosure | partial fan-out exit code 4 | accept | Exit code 4 discloses that some recipients failed; this is intentional and carries no sensitive information beyond the count |
| T-10-03-04 | Spoofing | send --to nonexistent session | mitigate | send_directed calls session_show(to_session_id) which validates liveness; SessionNotFound → emit_not_found + exit 2; no orphaned mailbox write |
| T-10-03-05 | DoS | broadcast machine scope to many sessions | accept | Fan-out is bounded by live session count on one machine (realistically <100); each iteration is one XADD + one PUBLISH; plain loop (no pipeline) allows per-recipient error tracking |
| T-10-03-06 | Tampering | scope parameter in broadcast/subscribe verbs | mitigate | _resolve_scope_key in ops layer validates scope against explicit allowlist; ValidationError propagated via verb shell → emit_error + exit 1 |
