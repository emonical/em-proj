<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| daemon HASH → os.kill | pid from Redis crosses to OS signal delivery — wrong pid = DoS/security breach |
| session stop verb → daemon HASH | session_id from resolve_session_id() scopes the stop to the caller's own daemon |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02-01 | Tampering | _daemon_stop os.kill before is_holder_stale check | mitigate | is_holder_stale(record) called before os.kill; if True → DEL + return stale_record_cleared without any kill; pid recycling (proc_start_epoch + boot_id triple) prevents SIGTERM to wrong process per RESEARCH Known Threat |
| T-11-02-02 | Denial of Service | Stale daemon HASH blocks new daemon starts | mitigate | _daemon_start calls _daemon_record_write (Lua write-or-detect); if existing record returned, is_holder_stale check: stale → _daemon_record_del + fresh Popen; live → return already_running (no block) |
| T-11-02-03 | Denial of Service | Double-start spawns two daemons (Lua race window) | mitigate | _daemon_foreground_run also calls _daemon_record_write as first step; if existing live record found: sys.exit(0); Lua atomicity ensures only one writer wins; second daemon exits cleanly per RESEARCH Pattern 3 race-condition note |
| T-11-02-04 | Tampering | session stop stopping another session's daemon | accept | session stop uses resolve_session_id() as the HASH key; each session_id maps to its own daemon:<session_id> HASH; cross-session stop would require knowing the target session_id and spoofing the env var (out of scope for this threat model — single-user, single-machine) |
| T-11-02-05 | Denial of Service | ProcessLookupError on os.kill after stale check passes (race: daemon exits between check and kill) | mitigate | ProcessLookupError caught explicitly; _daemon_record_del called; return {"status": "stopped"}; session is never wedged |
</threat_model>
