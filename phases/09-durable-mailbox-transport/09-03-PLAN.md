<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI user → inbox_cmd | --since is caller-supplied and passed to mailbox_inbox; --peek is a flag (no injection risk); session_id resolved from env var, not from CLI args |
| inbox_cmd → _ops.mailbox_inbox | session_id from resolve_session_id() (env-var-derived); since from CLI arg (string passed to XRANGE min) |
| cli.py → Redis | die_if_redis_unreachable called before any op; connection errors surface as exit 1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03-01 | Spoofing | inbox_cmd: session_id resolved from CLAUDE_CODE_SESSION_ID env var | accept | Same trust model as session_register and all v1.0 verbs; single-user machine-local; env var is set by Claude Code harness; no caller-supplied session_id in the inbox verb |
| T-09-03-02 | Tampering | inbox_cmd: --since <id> passed to mailbox_inbox as raw string | mitigate | mailbox_inbox passes since to _build_mbox_key (only uses session_id) and to XRANGE min as '(<id>'; Redis XRANGE rejects malformed IDs with an error (not a data leak); the '(' prefix is prepended by _ops code; at-most an invalid XRANGE returns [] — no data corruption |
| T-09-03-03 | Denial of Service | inbox_cmd: reads entire mailbox in one call (no pagination) | accept | Bounded by MBOX_MAXLEN=500 entries maximum; each entry is at most MAX_BODY_CHARS + overhead bytes; total output is bounded; pagination is a future UX enhancement, not a security boundary for Phase 9 |
| T-09-03-04 | Elevation of Privilege | cli.py: message_app mount gives any CLI user access to any session's inbox via ops layer | accept | The inbox verb resolves session_id from the env var (the caller's OWN session); there is no --session-id flag in the inbox verb; cross-session inbox reading would require the caller to set a forged CLAUDE_CODE_SESSION_ID env var — same trust level as all other operations in the project |
</threat_model>
