        Plain-text stderr: "em-proj: error: anonymous claims refused"
        JSON stderr: {"schema_version":"1","status":"error","error":{"code":"anonymous_claim","message":"anonymous claims refused"}}
        NOTE: this check must happen BEFORE any Redis call (D-18 order) and BEFORE die_if_redis_unreachable.

    claim verb:
      - Positional arg: area (str)
      - Options: --ttl <secs> (optional, int, min=MIN_TTL, max=MAX_TTL), --reason <text> (optional str), --json/--no-json
      - Flow: check CLAUDE_CODE_SESSION_ID → resolve json_mode → get_client() → die_if_redis_unreachable → call claim_take(area, ttl or TTL_DEFAULT, reason) → on success emit_ok({"area": area, "ttl": effective_ttl, "claimed_at": holder["claimed_at"], "expires_at": holder["expires_at"]})

    release verb:
      - Positional arg: area (str)
      - Options: --json/--no-json
      - Flow: resolve json_mode → get_client() → die_if_redis_unreachable → call claim_release(area)
      - On success: emit_ok({"area": area, "released": True}, json_mode=json_mode)
      - On HeldByAnother with holder=None: this maps to "claim not held (may have expired)" → emit_not_found(f"Area '{area}' is not claimed", json_mode=json_mode) → exit 2
        NOTE: "not held" is exit 2 (not_found), NOT exit 3.  See ROADMAP SC#3:
        "releasing another session's claim errors with exit code 3" — only the
        "held by another session" case is exit 3. A non-existent key is exit 2.
      - On HeldByAnother with holder (non-None): emit_held_by_another("held_by_another", f"Area '{area}' is held by session {e.holder['session_id']}", holder=e.holder, json_mode=json_mode) → exit 3
      - On ValidationError: emit_error(e.code, e.message)

    check verb:
      - Positional arg: area (str)
      - Options: --json/--no-json
      - Flow: resolve json_mode → get_client() → die_if_redis_unreachable → call claim_check(area)
      - On success (area IS claimed): ROADMAP SC#2 exit code 0.
        emit_ok({"area": area, "holder": holder}, json_mode=json_mode) where holder = full dict from claim_check
        TTY plain-text should render all 5 holder fields.
      - On ClaimNotHeld: emit_not_found(f"Area '{area}' is not claimed", json_mode=json_mode) → exit 2
        ROADMAP SC#2: "exit code 2 if not held"
      - NOTE: ROADMAP SC#2 also says "exit code 3 if held by another session". This check is
        the caller's responsibility once they have the holder dict — the check verb itself
        always exits 0 when held (regardless of who holds it) and 2 when not held. The
        exit-3-if-held-by-another semantics are for SDK consumers comparing against their own
        session_id; that comparison can be added as a --mine flag in Phase 5. Do NOT add that
        logic here.
