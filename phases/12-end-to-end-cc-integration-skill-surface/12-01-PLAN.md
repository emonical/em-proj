Locked decisions implemented here (NON-NEGOTIABLE, per 12-CONTEXT.md):
- "Hook scripts live IN THE REPO; wiring is REPO-SCOPED + env-gated (LOCKED)": scripts live under scripts/hooks/ (NOT ~/.claude/scripts/, which is session-registry.py's home); wiring lives in THIS repo's .claude/settings.json (SessionStart + UserPromptSubmit arrays), referencing scripts via $CLAUDE_PROJECT_DIR; participation gated on the literal env var EM_SESSIONS_AUTOSTART == "1"; unset means both hooks are an immediate no-op.
- "HOOK-01 SessionStart hook behavior": on gate-on, run `em-proj session register` then `em-proj session listen` (detached, idempotent — reuses the Phase 11 daemon lifecycle verbatim, no new session/daemon code).
